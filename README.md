# Projeto: Site Pessoal (HTML, CSS e Layout Responsivo)

- **Aluno:** Diandelys Castilho Wolff
- **Instituição:** UTFPR — Câmpus Dois Vizinhos (Engenharia de Software)
- **Objetivo:** Desenvolver um site pessoal de forma incremental em três etapas — começando com HTML puro, evoluindo para estilização com CSS externo e finalizando com layout responsivo seguindo a estratégia Mobile First.
- **Site publicado (GitHub Pages):** https://dwolff-blip.github.io/Atividade-1/

## Versões por Etapa (Branches)

O repositório mantém o histórico incremental na branch `main` (com a versão final publicada no GitHub Pages) e cada etapa registrada em sua respectiva branch:

- [`etapa-1-html`](https://github.com/dwolff-blip/Atividade-1/tree/etapa-1-html) — **Etapa 1:** Site pessoal com HTML5 puro e semântico (sem CSS ou JavaScript).
- [`etapa-2-css`](https://github.com/dwolff-blip/Atividade-1/tree/etapa-2-css) — **Etapa 2:** Estilização visual com arquivo CSS externo (`style.css`).
- [`etapa-3-responsivo`](https://github.com/dwolff-blip/Atividade-1/tree/etapa-3-responsivo) — **Etapa 3:** Reconstrução do layout com estratégia **Mobile First**, Flexbox/Grid e `media queries` para Tablet (`>= 768px`) e Desktop (`>= 1200px`).
