## Objetivo da Atividade
Desenvolver a primeira versão de uma página pessoal e portfólio utilizando exclusivamente **HTML5 puro** (sem uso de CSS, frameworks ou JavaScript), com foco na estruturação semântica correta do documento (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`), uso de títulos, parágrafos, listas, imagens (`<figure>` / `<img>`), hyperlinks e formulário de contato (`<form>`).
